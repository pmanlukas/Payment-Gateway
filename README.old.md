# MegaBank Payment Gateway

Enterprise Payment Processing System

## Overview

This is the payment gateway. It processes payments.

## Installation

1. Install Java
2. Run Maven
3. It should work

## Configuration

Edit the properties file. You know which one.

## Usage

Send a payment request. Check the code for details.

## API

We have an API. It's REST-ish.

### Endpoints

- POST /payments - Process a payment
- GET /transactions - Get transactions
- POST /refunds - Refund a payment

### Authentication

Use an API key. Ask Bob for one (Bob left in 2007).
